# My Journey

Локальный автономный сайт для планирования и отслеживания подготовки к K-pop audition.

## Запуск

Открой `index.html` в современном браузере. Сборка, сервер и установка зависимостей не нужны. Основные функции доступны офлайн. Данные остаются в localStorage конкретного браузера и устройства.

## Файлы

- `index.html` — каркас интерфейса и навигация.
- `styles.css` — адаптивный дизайн для компьютера и телефона.
- `app.js` — календарь, формы, локальное сохранение, таймер, статистика и резервное копирование.

## Что реализовано

- Главная панель с сегодняшними задачами, недельным расписанием, временем по направлениям, серией растяжки и целями.
- Календарь по дням, неделям и месяцам; добавление, редактирование, перенос дат и статусов задач.
- Стартовый двухнедельный план с ежедневными лёгкими танцами и растяжкой, регулярным корейским, вокалом и редкой силовой сессией. Будни запланированы после возвращения домой; день силовой — воскресенье.
- Разделы корейского по семи навыкам, темы грамматики, интервальные повторы слов, импорт CSV/JSON, чтение, аудирование, письмо, говорение и пробные TOPIK.
- Каталог танцев с четырьмя указанными хореографиями без выдуманных статусов, каталог песен и отдельные упражнения для вокала.
- 14-дневный трекер официального челленджа Chloe Ting; состав тренировок не выдуман, дату цикла можно назначить вручную.
- История растяжки, отметки самочувствия, дневник, месячные цели и отчёты день/неделя/месяц.
- Записи занятий с ручным вводом и таймером. Занятие можно связать с задачей, чтобы учесть его единожды.
- Автоматическое сохранение, JSON-экспорт/импорт с подтверждением замены данных, подтверждения удаления.

## Примечания

- После сброса браузерных данных записи можно восстановить из JSON-резервной копии.
- Состав каждого дня Chloe Ting пользователь вносит сам по официальной программе; внешние видео требуют интернет.
- TOPIK не предустановлен: целевой уровень выбирается в настройках, стартовая диагностика записывается вручную.
- Планировщик формирует шаблон на 14 дней; «Пересчитать расписание» добавляет только задачи в свободные интервалы и не переносит пропуски автоматически.
